# Data Dictionary

## Raw tables
- customers: customer demographics, acquisition, plan and churn label.
- courses: course catalog attributes.
- enrollments: customer-course enrollment and completion behaviour.
- user_activity: session-level engagement events.
- subscriptions: subscription lifecycle and renewal information.
- payments: transaction, refund and revenue information.
- feedback: NPS/review feedback.
- support_tickets: customer support interactions and resolution time.

## Processed table
- customer_360: customer-level analytical feature table used by Excel, Python and Power BI.
