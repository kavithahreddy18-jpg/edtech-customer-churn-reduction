# End-to-End Lineage

Raw CSVs → SQL data quality/cleaning → customer_360.csv → Python EDA & churn prototype → Excel KPI/segment analysis → Power BI PBIP semantic model → PBIR dashboard → business recommendations.

The dataset is synthetic and reproducible. The project is designed to demonstrate Business Analysis, data analysis, SQL, Python and BI workflow skills without representing fabricated results as real company data.
