# Business Analysis Requirements Summary

Source: Capstone Project 2 — EdTech Customer Churn Reduction Strategy

## Required analysis

1. Identify primary churn triggers across user segments.
2. Identify the lifecycle stage where churn peaks.
3. Analyze engagement metrics associated with retention.
4. Analyze the relationship between pricing and churn.
5. Identify interventions that could reduce churn.

## Data areas

- User demographics and course enrolments
- Behavioural data: login frequency, session time and completion
- Transaction data: subscriptions, renewals and refunds
- Feedback data: NPS, reviews and support tickets

## Methodology

- Cohort analysis
- Funnel analysis
- Engagement vs retention analysis
- RFM segmentation
- Behavioural clustering
- Basic Logistic Regression / Decision Tree churn prediction
- Fishbone analysis
- Pareto analysis
- User journey mapping
- Retention solution design
- A/B testing / experimentation framework

## KPI requirements

### Retention
- Customer Retention Rate
- Churn Rate
- Cohort Retention

### Engagement
- DAU / MAU
- Course Completion Rate
- Average Session Duration

### Business
- Customer Lifetime Value
- ARPU
- Renewal Rate

## Deliverables

- Research Report
- Dashboard
- Churn Prediction Model Prototype
- Strategic Recommendation Deck
