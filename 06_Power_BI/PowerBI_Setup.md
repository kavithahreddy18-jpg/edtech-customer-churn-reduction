# Power BI Setup

1. Download/clone the repository.
2. Open `06_Power_BI/EdTech_Churn.pbip` with Power BI Desktop.
3. Enable PBIP/PBIR/TMDL preview features if your Desktop build requires them.
4. Open `EdTech_Churn.SemanticModel/definition/model.tmdl`.
5. Replace the `ProjectRoot` value with the local repository root, for example `C:\\Users\\<you>\\edtech-customer-churn-reduction\\`.
6. Refresh the model.
7. The Overview page contains KPI cards and interactive visuals. Slicers/filters can be added or adjusted directly in Desktop.

The PBIP/PBIR/TMDL files are source-controlled text metadata. Microsoft documents this project format as Git/source-control friendly and supports opening a PBIP directly in Power BI Desktop.
