# Power BI Project

This folder contains a source-controlled **PBIP + PBIR + TMDL** project.

## Open
1. Open `EdTech_Churn.pbip` in Power BI Desktop.
2. If prompted, enable Power BI Project/PBIR/TMDL preview features.
3. In the semantic model TMDL, replace `C:\\REPLACE_WITH_PROJECT_ROOT\\` with the local root folder containing this repository.
4. Refresh the model.

The report uses the processed `customer_360.csv` as its import source and contains measures plus an executive dashboard.
