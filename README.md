# EdTech Customer Churn Reduction Strategy

An end-to-end Business Analysis and Data Analytics portfolio project focused on identifying customer churn drivers, segmenting learners, building a basic churn prediction framework, and designing measurable retention strategies.

> **Dataset note:** This project uses a synthetic but realistic EdTech dataset created specifically for this case study. It does not represent confidential or proprietary customer data.

## Business Problem

EdTech platforms can lose customers because of low course completion, weak post-onboarding engagement, expectation/content mismatch, pricing sensitivity, and perceived low ROI.

## Project Objectives

- Identify key churn drivers across the learner lifecycle
- Segment users by behaviour, intent, and value
- Build a conceptual/basic churn prediction model
- Recommend targeted retention interventions
- Define measurable KPIs

## Project Workflow

Raw synthetic data → Data quality & modelling → SQL analysis → Excel analysis → Python EDA/segmentation/model → Power BI dashboard → Root-cause analysis → Retention strategy

## Repository Structure

- **01_Business_Analysis** — business problem, requirements, research questions, journey and recommendations
